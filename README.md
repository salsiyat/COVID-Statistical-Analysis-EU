# Applied Statistical Analysis of COVID-19 Patterns Across EU/EEA Countries

Statistical analysis of COVID-19 transmission and mortality patterns across European countries using epidemiological modeling and regression techniques.

This project analyzes daily COVID-19 case and fatality data across EU/EEA countries, focusing on cross-country comparisons, hypothesis testing, correlation analysis, and predictive modeling.

## Key Components

- Epidemiological rate standardization
- Rolling average smoothing
- Cross-country hypothesis testing
- Correlation analysis
- Regression modeling
- Model validation
- Log-transformed predictive modeling

## Tools

- R
- RMarkdown
- Statistical modeling
- Linear regression
- Hypothesis testing

## Dataset Source

European Centre for Disease Prevention and Control (ECDC)
